# Partner logos

Two sets of third-party brand assets live here.

## Work providers (Partner Logo component)

Official marks exported verbatim from the Figma "Work Providers" set
(Design-System-003, node 3719-3954). Two forms per brand:

- `<brand>.svg` — the 72×72 Tile (brand-coloured square + mark), also used at
  Icon S (32) and Icon XS (24).
- `<brand>-wordmark.svg` — the logotype on the 269×72 frame.

Brands: deliveroo, vromo, amazon, bolt, ola, stuart, uber, uber-eats, freenow,
just-eat, ryde, gopher, gogetters, autocab, apache-pizza, absolutely,
one-delivery. (Apache Pizza, Absolutely and One Delivery are tile-only.)

Most are pure vector; a few (autocab, amazon-wordmark, autocab-wordmark) carry an
embedded raster. `gopher-wordmark.png` is a 3× raster — the brand's Figma SVG
wordmark export was malformed, so the PNG is used in its place.

## Aggregator partners (Aggregator Partners component)

White / monochrome wordmarks tinted via CSS `background-image`: comparethemarket,
gocompare, confused, quotezone, moneysupermarket, insuremy4less, drivescore.
Replace each with the partner's official white SVG, keeping the filename.
